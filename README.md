# PROMPT Mini-Chat

Um prompt de cinco fases que escreve a sequência completa de um mini-chat: a palavra-chave do comentário, a mensagem de convite com botão, a pergunta de qualificação e o teste antes de ligar.

## Como usar

1. Abra o Claude, o Claude Code ou o Codex.
2. Copie o bloco "O prompt" do arquivo [PROMPT-MINICHAT.md](PROMPT-MINICHAT.md), cole na conversa e envie.
3. Revise cada rascunho antes de aprovar. Ele não salva nada sem o seu "pode".

## Avisos

O prompt escreve os textos, não configura a ferramenta nem envia mensagens. Valide as regras da plataforma e o consentimento para contato (LGPD) com um profissional.
